# Telecom Customer & Revenue Analysis

## Project Overview

This project applies Python-based statistical analysis to customer behavior and revenue data for two telecommunications plans.

## Objectives

- Prepare and clean customer datasets
- Analyze customer usage behavior
- Examine calling, messaging, and internet usage
- Calculate and analyze revenue
- Compare customer behavior between plans
- Perform statistical hypothesis testing
- Develop conclusions based on the analysis

## Technologies & Libraries

- Python
- Pandas
- NumPy
- SciPy
- Matplotlib

## Analysis

The project examines customer usage patterns across:

- Phone calls
- Call duration
- Text messages
- Internet usage
- Monthly plan behavior
- Revenue

The analysis combines data preparation, aggregation, exploratory analysis, and statistical testing.
